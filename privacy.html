Privacy

This page explains what the Garden website and desktop application do with data.

This website

The Garden website does not use analytics, advertising trackers or cookies.

When the download page loads, it requests public release information from the GitHub API so it can offer the right installer for your operating system. Your browser makes that request directly to GitHub, subject to GitHub’s privacy statement.

The Garden application

Garden stores its project data locally, in the project’s .agentproject/ folder by default or in the application data folder if you change that setting.

Garden runs the agent providers you configure, including Codex, Claude Code and local models. Requests sent to a hosted provider are handled under that provider’s terms and privacy policy. Local model behaviour depends on the local service you connect.

Source code and questions

Garden is open source. You can inspect the code or report a privacy issue through the Garden repository on GitHub.
